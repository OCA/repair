This module extends **Repair Analytic** to include timesheet costs in
the analytic distribution calculation when a repair order is completed.

When a project has **Spread Timesheet Cost on Repair** enabled, the
labor costs from timesheets linked to that project will be distributed
across the repair order's analytic accounts according to its configured
analytic distribution.

Usage
=====

1. Enable **Analytic Accounting** in Accounting settings.
2. On the desired project, go to **Settings** tab and enable **Spread
   Timesheet Cost on Repair**.
3. On a repair order, configure the **Analytic Distribution**.
4. Register timesheets on the repair order linked to the project above.
5. When the repair order is confirmed as **Done**, analytic lines will
   be created for both the parts used and the timesheet costs,
   distributed according to the configured analytic distribution.
6. On cancellation or deletion of the repair order, the generated
   analytic lines are automatically removed (timesheet entries
   themselves are preserved).
