## Consignment (Stock Ownership Tracking)

This module requires the **Consignment** feature (*Inventory → Configuration →
Settings → Traceability → Consignment*) to be enabled so that stock pickings
track the owner of the goods.

The feature is **enabled automatically** when this module is installed via a
post-install hook. No manual configuration is required.

## Supervisors

Each repair group has a **Supervisor** field. Assign the user responsible for
approving repair orders in the group. By default, the user who creates the group
is set as supervisor.
