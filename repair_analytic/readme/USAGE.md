1. Go to **Inventory → Configuration → Operation Types** and open a Repair
   operation type. In the **Analytic** section, set **Analytic Price Type** to
   *Price* (uses sale price) or *Cost* (uses product cost).

2. Open a repair order and set the **Analytic Distribution** field (visible only
   for users with analytic accounting enabled).

3. Add parts (Added, Removed or Recycled), start and complete the repair.
   Analytic journal entries are created automatically and accessible via the
   **Analytic Lines** smart button.

4. Cancelling or deleting the repair order removes all linked analytic entries.
