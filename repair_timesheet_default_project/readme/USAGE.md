1. Go to **Settings \> Repair**.
2. Under **Repair Timesheets Default Project**, set the **Default
   Project** and **Default Task** to be used for Repair Order
   timesheets.
3. On any Repair Order, open the **Timesheets** tab and add a new line:
   **Project** and **Task** are pre-filled with the configured defaults,
   so only **Date**, **User**, **Description** and **Duration** need to
   be filled in.
